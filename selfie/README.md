# 光室 Darkroom — 自拍美顏相機

單頁 PWA，可以裝到手機主畫面、離線使用。沒有後端，**照片全程留在你的裝置上，不會上傳到任何地方**。

## 功能

- **自拍**：前鏡頭即時預覽（鏡像），磨皮與色調直接套在預覽上，按快門後可繼續微調
- **美顏**：磨皮、亮膚、紅潤、銳利（只作用在膚色區域，會避開眼睛髮絲等高反差邊緣）
- **臉型**：瘦臉、大眼、短下巴。載入照片時自動偵測臉的位置，可手動拖曳微調
- **濾鏡**：柔光、淨白、暖陽、底片、冷調、黑白、濃郁（縮圖用你自己的照片即時運算）
- **調整**：亮度、對比、飽和度、色溫、褪色、暗角
- **旋轉裁切**：轉 90°、水平／垂直翻轉、1:1 / 4:5 / 9:16 / 4:3
- **錄影**：錄的是套好美顏的預覽畫布，所以影片裡就是你看到的樣子；可收音，錄影中仍可調整參數
- 按住畫面看原圖對比
- 儲存時用原始解析度重新運算（最長邊上限 3000px），不是存預覽縮圖

## 部署

放到任何支援 HTTPS 的靜態空間即可（相機必須在 HTTPS 下才能使用）。
GitHub Pages：把 `dist/` 內容推到 repo，Settings → Pages → Source 選 `main` 分支根目錄。

## 安裝到手機

用手機瀏覽器打開網址：

- **iPhone（Safari）**：分享鍵 → 加入主畫面
- **Android（Chrome）**：右上選單 → 安裝應用程式／加到主畫面
